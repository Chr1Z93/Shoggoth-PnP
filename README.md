# Info
This repository contains [shoggoth](https://github.com/tokeeto/shoggoth) projects for officially-approved PnP projects for Arkham Horror: The Card Game.
This includes taboo cards, errata cards, parallel investigators and more.

# Translating
The primary use-case is to create translated content for countries / locales that do not get official files for these cards. This is a supported feature by shoggoth - only the changed data (text fields) is required. Other fields will be inherited from the primary (english) project file.

# Content
## Taboo
The taboo list is an by FFG curated list of changes to improve the balancing of cards. Using the taboo list is optional.
- Chapter 1: latest update was FAQ 2.5 (February 2026)
- Chapter 2: no taboo list yet

## Errata
Some cards end up being misprinted or with wrong wording. The errata list corrects these things. Errata is not optional.
- Chapter 1: latest update was FAQ 2.5 (February 2026)
- Chapter 2: latest update was Grimoire 1.1 (July 2026)

## Parallel Investigators
There are some versions of investigators from a "parallel universe". These are usually very similar, but feature a new twist. Parallel investigators can usually be "mixed and match" - you can use the regular front and the parallel back for example. These investigators usually feature advanced or replacement signatures and might come with a challenge scenario.

## Promos
For specific events, FFG releases special promo cards. ATM these are outside of the scope of this project since they require a lot of manual work, but I'm listing them here for completeness.
